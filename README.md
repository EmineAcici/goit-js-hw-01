# GoIT JavaScript Homework 01 - Temel JavaScript Fonksiyonları

Bu proje, GoIT Full Stack Developer eğitimi kapsamında hazırlanan ilk JavaScript (JS) ödevidir. Ödev, temel matematiksel işlemler, fonksiyon tanımlama, parametre yönetimi ve string manipülasyonu konularını kapsamaktadır.

## 🚀 Proje Yapısı

Ödev, her biri ayrı bir mantıksal görevi yerine getiren üç farklı JavaScript dosyasından oluşmaktadır:

```text
goit-js-hw-01/
├── js/
│   ├── task-1.js    # Droid Siparişi Hesaplama
│   ├── task-2.js    # Ürün Teslimat Mesajı
│   └── task-3.js    # Öğe Genişliği Hesaplama (Box-sizing)
└── index.html       # Konsol çıktılarını izlemek için ana dosya
